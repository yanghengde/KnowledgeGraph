CamstarOntology 是面向 Siemens Opcenter Execution，也就是 Camstar MES 的本体知识图谱平台。

它将 Camstar 数据库中的物理表、字段和外键关系，转换成统一、可阅读、可验证的本体模型。目前部署系统覆盖 593 个类、8337 个属性和 1592 条关系。

平台首先以 Database_Tables.csv 和 Database_Fields.csv 为物理事实来源。普通字段映射为数据属性，物理外键统一映射为 Navigation，并通过自动校验发现缺失属性、类型不一致和关系遗漏。验证后的本体可以批量加载到 Neo4j。

在前端，用户可以搜索 Container、Workflow、Product 等业务对象。搜索会立即突出匹配节点；打开节点详情后，可以查看字段类型、字段说明、Navigation 目标，以及对象的入向和出向关系。

查询构建器允许用户直接在图谱中选择业务对象，验证真实的物理 JOIN 路径，并生成 Oracle 或 SQL Server 查询骨架。SQL 助手还可以把图谱对象加入上下文，辅助生成只读查询。

通过统一建模、自动验证、关系可视化和智能协作，CamstarOntology 让复杂的 MES 模型更容易理解、治理和复用。
