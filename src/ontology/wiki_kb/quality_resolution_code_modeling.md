Chapter : Quality Resolution Code Modeling
Introduction
The QualityResolutionCode entity (CdoId: 7709) defines disposition resolution codes
used in quality events and CAPAs (e.g., return to vendor, concession, rework, scrap).

In This Chapter
- QualityResolutionCode (Quality Resolution Code)

Field Definitions:
- Name (String, Required): Unique resolution code name.
- Plus standard fields: Description, Notes, FilterTags, IsFrozen, InstanceLocked, ChangeHistory, IconId.
