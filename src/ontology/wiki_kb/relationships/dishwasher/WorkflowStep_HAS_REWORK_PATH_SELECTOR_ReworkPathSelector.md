## 关系说明

在 Siemens Opcenter (Camstar) 建模中，`WorkflowStep` 表示生产流程中的一个具体工序或操作步骤。当该步骤内出现需要返工处理的产品（如洗碗机在装配或测试中发现的瑕疵或失败品），系统需要根据缺陷类型或条件将产品导向不同的返工路径。`ReworkPathSelector` 即为定义这种条件分支的逻辑容器：每个选择器包含一个条件表达式（如基于缺陷代码、测试结果、产品属性等）以及一个目标返工步骤。由于一个步骤可能对应多种返工场景（例如漏水、噪音、划伤等需不同处理方式），因此一个 `WorkflowStep` 可关联多个 `ReworkPathSelector`，形成一对多的关系。

在洗碗机产线中，此关系尤为关键。洗碗机生产涉及钣金成型、内胆焊接、门体装配、电气布线、性能测试等多个复杂工序，每个工序都可能出现特定类型的缺陷。通过配置多个返工路径选择器，生产管理者可以精细控制返工流程：例如，在“最终性能测试”步骤中，根据测试数据将产品分流至“泄漏修复线”、“电机更换工位”或“控制板刷新工位”，从而避免不必要的全流程返工，提高效率。

## 业务场景

### 何时需要配置此关系？
- **不同缺陷类型对应不同修复流程**：例如在“门体密封检测”步骤，发现“密封条偏移”与“密封条断裂”两种缺陷，前者可在原工位调整，后者需拆下门体送至粘合工作站，必须分别配置选择器。
- **产品型号或变体导致返工路径差异**：洗碗机分为独立式、嵌入式、紧凑型等不同型号，某些返工操作（如控制固件升级）仅适用于带智能模块的型号，需要按产品类型条件分流。
- **基于数据驱动的动态返工决策**：在“电气安全测试”步骤，测得的绝缘电阻值若低于阈值但高于第二阈值，则进入“再干燥处理”工位；若低于第二阈值则直接报废。不同阈值区间对应不同选择器，且可借助表达式动态评估。

## 配置要点

1. **条件表达式需精确且无冲突**：多个选择器的条件应互斥，或通过优先级确保唯一匹配。避免出现一个产品同时满足两个选择器而导致路由不确定性。
2. **选择器优先级影响执行顺序**：在 `WorkflowStep` 中，选择器按列表顺序（从上到下）依次评估，一旦匹配即选定返工路径，不再继续检查后续选择器。建议将最特殊或紧急的缺陷类型放在前面。
3. **目标返工步骤必须存在于流程模板中**：且通常需标记为 `Rework Step` 类型，确保系统能正确识别并允许产品返工后重新进入主流程。
4. **考虑返工后的重新测试逻辑**：返工步骤完成后的 Next Step 应指向原步骤或相关测试步骤，否则会出现流程中断。可在选择器配置中指定 `Return To Parent Step` 或显式设置下一步。
5. **支持引用外部变量**：条件中除了缺陷代码，还可使用测试测量值（如 `TestResult.Value > 200`）、产品属性（如 `Product.Attribute.Model = "HighEnd"`），或站点/工位属性，实现灵活的分支。
6. **避免循环返工**：注意检查返工路径的 Next Step 是否会导致无限循环（例如返工步骤又回到原选择器步骤），必要时设置最大返工次数或通过超时限制。
7. **在 Camstar 用户界面中的位置**：进入目标 `WorkflowStep` 属性页，切换到 **Rework Path Selectors** 选项卡，即可添加、删除或调整选择器顺序。
8. **测试与验证**：在仿真环境或 Pilot 产线中，使用不同的缺陷码/测试值触发返工，确认产品按预期路由，并检查数据记录（如返工历史跟踪）是否正确。

## 常见问题 FAQ

**Q: 如果一个产品同时满足多个选择器的条件，会如何执行？**  
A: 系统按照选择器在列表中的顺序从上到下依次评估，一旦匹配第一个选择器即执行该返工路径，后续选择器不再检查。因此，请通过调整顺序定义优先级。如果希望多条件并列（如同时需要两个返工操作），则需要设计复合返工步骤，而非使用多个选择器。

**Q: 配置条件时可以使用脚本或自定义函数吗？**  
A: 可以。支持 Opcenter 表达式引擎，包括内置函数和自定义脚本（如 C# 或 JavaScript 脚本）。例如，可以编写脚本检查多个测量值的组合或调用外部 Web 服务。但在大多数标准场景中，使用简单的字段比较表达式即可。

**Q: 返工路径的“目标步骤”必须是与原步骤同一流程模板中的步骤吗？是否可以是不同流程中的步骤？**  
A: 在标准配置中，目标步骤必须属于当前流程模板（Workflow），且通常是该流程中的已有步骤。如果希望将产品转移到另一个完全不同的流程（例如进入专门的返工产线），需要通过路由规则或外部系统集成实现，而不是直接在本选择器中设置跨流程步骤。
