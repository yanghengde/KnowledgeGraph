## 关系说明

在 Siemens Opcenter MES（Camstar）中，`BOMItem` 到 `Spec` 的 `ASSIGNED_TO_SPEC` 关系，用于将物料清单中的一行物料（BOMItem）与一个特定的生产规范（Spec）绑定，指明该物料在哪个操作步骤被实际消耗。基数 `MANY_TO_ONE` 表示多个不同的物料行可以被分配给同一个 Spec，但每一个 BOMItem 最多只能绑定一个 Spec（可选绑定）。

对于洗碗机产线而言，这一关系是实现“按工步精准消耗物料”的核心配置。洗碗机装配流程通常包含数十个工位和上百种物料，物料消耗往往不是在产线起点一次性投入，而是在某个具体操作步骤（如安装电机、接水管、锁门封）时才被拉取使用。通过此绑定，MES 能够在操作员执行对应 Spec 时自动触发物料扣减，实现精细化物料流管理和防错，同时为可追溯性提供每一步物料使用的精确记录。

需要注意的是，该关系是可选的：如果 BOMItem 未绑定任何 Spec，则物料消耗会在该 BOMItem 关联的工位（WorkCenter）或默认的路径步骤中被处理，具体行为依赖于系统配置。但在洗碗机产线这类复杂装配场景中，强烈建议对关键物料进行 Spec 绑定，以提升过程控制精度。

## 业务场景

### 何时需要配置此关系？

- **场景一：区分不同工步使用相同物料**  
  洗碗机中常有不锈钢螺丝、密封垫、扎带等通用物料，在不同装配步骤（如安装喷淋臂、固定加热管）中被使用。为了准确统计每个工步的消耗量并避免混料，需要将同一种物料的不同 BOMItem 行分别绑定至对应的 Spec。

- **场景二：防错与关键物料绑定**  
  关键部件如主控板、洗涤泵、门锁等，必须在正确的工步被安装，错误的步骤使用将导致严重质量缺陷。通过 `ASSIGNED_TO_SPEC` 绑定，MES 可强制要求操作员只有在执行绑定的 Spec 时才能领用该物料，有效防止错装、漏装。

- **场景三：支持 SFC（序列化批次）的物料追溯**  
  当洗碗机以唯一序列号 (SFC) 流转时，需要记录每个序列号在每一步使用的物料批号。将 BOMItem 绑定到 Spec 后，MES 会在执行该 Spec 时自动记录该序列号消耗的物料，为后续追溯提供完整链路。

### 洗碗机产线 典型示例

**示例**：在洗碗机装配线“加热部件安装”工位，需要安装加热管（Heater）、加热器密封垫（Gasket_Heater）和固定螺丝（Screw_Heater ×4）。配置如下步骤：

1. 在 Opcenter 中创建 Spec，名称为 `INSTALL_HEATER`，描述为“安装加热管及密封件”。
2. 创建对应的 BOMItem 行（物料清单条目）：
   - BOMItem 行号 10：物料编码 `HEATER-001`（加热管），数量 1
   - BOMItem 行号 20：物料编码 `GASKET-HEATER-001`（密封垫），数量 1
   - BOMItem 行号 30：物料编码 `SCREW-M4x10`（固定螺丝），数量 4
3. 为每个 BOMItem 配置 `ASSIGNED_TO_SPEC` 关系：分别选择 Spec `INSTALL_HEATER`。
4. 在生产时，当 SFC 进入 `INSTALL_HEATER` 步骤，操作员执行该 Spec，MES 自动触发三个物料的消耗扣减（根据当前 SFC 和 Spec）。
5. 若加热管被错误地分配到其他工步（如安装门封），则 MES 拒绝发料并提示报错。

## 配置要点

1. **一个 BOMItem 只能绑定一个 Spec**：基数 MANY_TO_ONE 意味着从 BOMItem 的角度是单向绑定到唯一 Spec。如需物料在多个步骤使用，必须创建多个 BOMItem 行（如不同行号），分别绑定不同 Spec。
2. **Spec 必须已定义并处于激活状态**：绑定的 Spec 需要先在建模工具中创建，且建议状态为“已发布”或“已启用”，否则生产时无法被引用。
3. **考虑物料消耗时机与 Spec 执行顺序**：绑定后，物料扣减发生在执行 Spec 的操作确认时刻。如果物料在 Spec 执行前就应被领用（如预装物料），则可能需要调整 Spec 内的操作逻辑或使用其他机制。
4. **影响物料可用量计算**：绑定 Spec 后，系统会在 Spec 执行时实时扣减库存，若未绑定则可能在工位级别或批次完成时扣减。需根据实际库存管理需求选择。
5. **与 BOM 版本联动的注意事项**：如果 BOM 需要版本管理（例如工程变更），绑定关系同样会随版本切换。变更时需确保新版本中的 BOMItem 与 Spec 关系正确更新，避免未绑定导致的物料异常。
6. **配合物料防错验证**：若要实现“仅绑定的 Spec 才能消耗该物料”，还需在 Spec 或设备上启用物料防错配置（如物料扫描确认），否则操作员仍可能通过其他方式手动消耗。
7. **多语言或标签打印**：如果需要在 Spec 执行时打印物料标签或生成追溯信息，需在 Spec 对应的生产表单或脚本中调用 BOMItem 属性，建议提前测试绑定关系对模板数据源的影响。
8. **性能考量**：当 BOMItem 数量巨大（如数千行），批量配置 ASSIGNED_TO_SPEC 关系时注意数据导入效率，建议使用 Opcenter 的批量导入工具（如 Excel import）并合理分片。

## 常见问题 FAQ

**Q: 一个 BOMItem 是否可以绑定多个 Spec？**  
A: 不可以。基数 MANY_TO_ONE 决定了每个 BOMItem 只能绑定一个 Spec。如果需要同一物料在多个工步使用，应在 BOM 中创建多条物料行（例如不同行号），每条行再分别绑定不同的 Spec。

**Q: 如果某 BOMItem 没有绑定任何 Spec，生产时物料会什么时候被消耗？**  
A: 未绑定 Spec 的 BOMItem，其消耗时机取决于 BOM 与路径（Route）的关联方式。通常，系统会将该物料消耗关联到 BOM 所在工位（WorkCenter）的默认步骤，或在该工位的任意操作完成时消耗。具体行为需查看系统的“默认消耗规则”。建议对需要精确控制的物料显式绑定。

**Q: 在洗碗机产线中，绑定关系配置错误会导致什么后果？**  
A: 典型的后果包括：  
- 物料无法在指定工步被发料，导致该工步缺料而暂停生产。  
- 若绑定的 Spec 不存在或未激活，系统会报错并阻止操作。  
- 物料消耗记录不准确，影响成本核算和追溯。  
- 若多个 BOMItem 行指向同一 Spec，但其中某个行参数错误，可能导致多消耗或少消耗物料。因此，建议在测试环境（如模拟 SFC 运行）中验证关系后再上线。
