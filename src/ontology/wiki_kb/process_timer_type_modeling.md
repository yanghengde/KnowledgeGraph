Chapter : Process Timer Type Modeling
Introduction
The ProcessTimerType entity defines timer type categories used with ProcessTimer
to classify different time-tracking scenarios in workflow processes.

In This Chapter
- ProcessTimerType (Process Timer Type)

ProcessTimerType
A named catalog entry (CdoId: 8637) classifying timer types in process workflows.

Field Definitions:
- Name (String, Required): Unique timer type name.
- Description, Notes, FilterTags, IsFrozen, InstanceLocked, ChangeHistory, IconId.
