# 模型审阅与发布

打开 `/app/ontology-model`，默认进入“来源与转换”。先定义来源用途，再审阅业务本体。

## 从原始表逐步探索

打开左侧“Camstar 数据模型”（`/app/object-explorer`）。选择系统说明来源，然后点击“读取项目标准表结构”，直接读取项目中的只读 CSV；也可展开上传区使用自己的表定义和字段文件。

1. 在左侧按表名搜索，不区分大小写。点击表查看完整物理字段，包括主键、技术字段和系统字段。初始不预选表，按本次建模范围选择来源。
2. “引用对象”显示该表的外键终点；“被哪些对象引用”显示外键来源。点击关联表继续探索，可通过顶部路径或“返回”回到之前的对象。
3. 关系行保留原始字段和目标字段。同一对表的多条外键分别显示；CSV 中缺失的目标会标明，不能作为本次候选选择。
4. 中文说明与英文原文并列展示。对象说明后台读取并翻译；“物理字段”页签可按需读取并保存字段的中英文说明。失败可重试，已完成部分会复用，不编造缺失的系统说明。
5. 点击“保存物理模型”，将全部原始表、字段行保存为 PostgreSQL 不可变结构快照。可在“打开已保存的物理模型”中重新打开；重复保存相同结构不会产生重复版本。
6. 在底部将已选表加入语义建模草稿，此操作也保存完整物理快照。点击“前往来源与转换”定义业务用途。重复选择同一快照中的同一张表会保留已有设计，不覆盖编辑结果。

## 来源用途与字段映射

1. 在“来源与转换”选择来源表，指定实体、事件、关系、辅助或暂不采用；新来源默认为待评估，不根据 History 等表名自动批准用途。
2. 填写业务名称、定义和转换设计说明。事件来源建议记录行为判别、关联明细、事件身份、时间和撤销规则；说明用于设计评估，不是可执行 SQL。
3. 对一表一实体映射，明确字段用途：业务属性、业务关系、仅内部使用或不纳入本体。Navigation 外键可映射业务关系，不能作为普通标量属性。主键必须保留，默认仅内部使用。
4. 可将剩余待评估字段批量设为不纳入，并逐项恢复。隐藏不纳入字段只改变显示；物理快照不会删除字段。保存设计使用修订号检查，旧页面不能覆盖新修改。
5. 保存后预览候选，检查属性、关系、内部及排除字段数量。未评估字段、缺失身份键和缺失外键目标阻止生成。确认后才创建不可变候选，并进入本体设计审阅。

当前生成器支持一表一实体的明确字段投影。事件拆分、关系表转换和多表组合仅保存设计，尚不执行转换或创建业务实例；这类来源必须完成具体业务转换规则后再接入发布链路。

结构快照保存在 `graphsync.physical_model_snapshot`，来源草稿保存在 `graphsync.semantic_mapping_draft`，与活动本体及发布版本分离。草稿中的字段用途和身份依据随生成的候选、权威版本保存；来源变化会要求重新评估，不自动扩展已批准字段。

双语来源说明存储在 PostgreSQL `graphsync.designer_description`，按源系统、对象、字段与英文内容版本保存；英文变化会保留旧版本。它与已批准的业务定义分开管理。候选同时携带 `descriptionEn` 和 `descriptionZh`，默认以中文作为展示说明。项目原始 CSV 不会被修改。

后台翻译沿用 `.env` 中的 `IMPORT_TRANSLATION_PROVIDER` 及翻译服务配置。导入分析会话有效期为一小时，过期后重新读取 CSV；已持久保存的说明可以复用。源系统没有提供英文说明的对象仍可浏览外键和加入候选。

## 审阅与发布

1. 从“来源与转换”生成候选后，在“本体设计”的对象目录中审阅。目录默认显示全部对象，可筛选待确认与导入候选；“已同步模型图”展示已同步建模库的内容。
2. 选择字段定义、中文名称和业务域，预览新增、修改与移除差异。带来源映射的模型只纳入明确选择的属性和关系，其他来源不能将排除字段合并回来。物理结构和外键仍需符合项目只读 CSV。
3. 确认权威修订，再同步至 PostgreSQL 源模型。缺失关系终点会阻止同步；模型快照与同步状态在同一事务内保存。
4. 将所需对象加入“发布范围”，选择核心对象、字段及关系用途。物理外键是候选依据，需要业务审阅。
5. 校验工作区，冻结不可变模型版本，按发布流程批准和激活。源模型审阅不会自动发布到 Graph Studio。
6. 在数据同步页生成经验证的数据版本，进入发布页选择 Dev 路由。发布成功后才更新发布 checkpoint。

来源变化会使旧预览失效，需重新预览和确认。PostgreSQL 保存候选、权威修订、工作区、冻结版本、审计和回滚指针，应纳入数据库备份。

`src/ontology/wiki_kb/*_ontology.json` 是现有来源语义定义，仅供候选比较。已发布模型以 PostgreSQL 冻结版本及 Graph Studio 实际发布状态为准。

在同一浏览器标签页中切换菜单或刷新时，会恢复有效期内的对象选择、搜索和探索路径。更换结构来源会开始新的选择；分析会话过期或后端重启后，需重新读取结构。双语说明始终保存在 PostgreSQL。
